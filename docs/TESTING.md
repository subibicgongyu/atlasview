# 테스트 안내

Windows x64와 .NET Framework 환경에서 다음 명령을 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
```

현재 버전의 자동 검사 134개가 통과했습니다. 합성 샘플을 이용해 다음 동작을 검사합니다.

- DDS/GTF/G1T, BC1/2/3, 색상·알파, Morton, LZP2 및 입력 범위 검사
- 메모리 캐시 재사용과 원본 변경 감지, 디스크 캐시 파일 생성 없음
- 리소스 단위 그룹과 여러 리소스의 묶음 표시
- 숨김 목록 페이지·검색·복원, 비동기 미리보기 취소 및 최신 선택 반영
- 미번역 개별·일괄 기록, 저장 실패·취소 시 기존 기록 보존
- PNG 내보내기와 원본 입력 보존

결과는 로컬 `artifacts/tests/tests.json`에 기록됩니다. 실제 게임 파일, 사용자 기록, 디버그 덤프와 개인 경로·원본 해시를 포함하는 진단 문서는 저장소에 포함하지 않습니다.

자동 검사는 모든 게임의 전용 형식 지원이나 실기 호환성을 보장하지 않습니다. 게임 실행·플레이 검증은 수행하지 않습니다. 지원 형식과 한계는 README를 참고하세요.
