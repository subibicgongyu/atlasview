# 개발 구조와 형식 근거

## 현재 캐시 동작

디스크 캐시 구현과 최근 이미지 복원 UI를 제거했습니다. PreviewLoader는 메모리만 재사용하며 원본 읽기 외 캐시 파일 I/O를 수행하지 않습니다. 파일 경로·오프셋 기반 영구 리소스 ID는 동일한 UTF-8 SHA-256 알고리즘을 Bin.TextHash로 옮겨 숨김·미번역 키 호환성을 유지합니다. 시작 시 이전 폴더 경로만 복원하고 사용자가 다시 검색합니다.

## 현재 리소스 단위 동작

숨김 관리 UI는 `src/HiddenImagesDialog.cs`로 분리했다. 200개씩 실제 ListView 행을 만들고, 정렬된 메모리 스냅샷을 검색한다. 입력은 180ms 지연 후 필터를 갱신하며 체크 이벤트에서는 O(1) 개수만 읽는다. 전체 검색 결과 체크는 HashSet 일괄 갱신 후 현재 페이지만 그린다. 체크는 페이지/검색과 독립된 키 집합이다.

숨김 미리보기는 별도 PreviewLoader의 메모리 캐시를 사용하고 Task 작업으로 수행한다. SemaphoreSlim으로 디코딩을 직렬화하며 선택 변경/닫기 시 취소, 세대 번호로 이전 결과 표시를 방지한다. `src/HiddenPreview.cs`는 현재 검색 메타데이터를 우선 사용하고 없으면 저장 경로+오프셋에서 PNG/JPEG/BMP/GIF·DDS·GTF·G1T·LZP2 헤더와 범위를 확인해 해당 리소스만 읽는다. 새 RAW 숨김은 `PreviewTexture`에 해석 설정을 저장한다. 과거 RAW 항목에 해석 정보가 없거나 원본이 없으면 오류만 표시하고 숨김 기록은 유지한다.

`src/ResourceBatch.cs`는 현재 필터 목록을 기본 8개(1~32 변경 가능)씩 나누는 표시 전용 묶음입니다. 왼쪽 목록/숨김/미번역/캐시의 리소스 ID는 변경하지 않습니다. `ResourceBatchPreview`는 각 이미지의 ResourceGroup·Texture·클릭 사각형과 리소스별 SourceStamp를 유지하고 원본 위치를 타일에 표시합니다. 전체 이미지 4096개 이내, 최대 8열/변 8192px로 제한하며 초과 시 묶음 크기를 줄이라는 오류를 표시합니다. 같은 묶음 안에서 선택만 바꾸면 다시 디코딩하지 않습니다.

이미지 클릭은 왼쪽 선택과 청록색 테두리를 동기화하고 H/단일 기록 대상을 바꿉니다. 이 동기화는 목록의 비동기 미리보기 이벤트를 억제해 불필요한 재로딩을 방지합니다. 일괄 숨김 `HideMany`는 단일 원자적 저장으로 개별 리소스 키를 추가합니다. 일괄 미번역 `SaveResources`는 모든 PNG/소스 버전 검증 이후 JSON을 한 번 커밋합니다. 취소·실패 시 이전 JSON이 유지되며 이미 생성한 스냅샷 PNG는 남을 수 있습니다. 일괄 작업도 개별 관리가 가능하며 표시 묶음을 영구 리소스 ID로 합치지 않습니다.

미번역 기록의 원본 경로+오프셋 ID 집합을 앱 시작과 관리 창 닫기에서 읽고 메모리에 유지합니다. `Refilter`는 숨김과 미번역 기록을 모두 제외하므로 검색 목록에서도 동일하게 적용되며 필터 입력이나 이미지 선택마다 JSON을 읽지 않습니다. 저장 성공 후에만 집합에 추가하고 다음 리소스로 이동합니다. 기록 제거 시 관리 창을 닫으면 집합을 갱신해 다시 표시합니다. 숨김 상태는 독립적으로 유지합니다.

`src/Resources.cs`의 `ResourceGroup`은 정규화 절대 파일 경로와 `Source.Offset`로 묶습니다. `resource-v1|경로|오프셋`의 SHA-256이 리소스 ID입니다. 목록은 200개 리소스씩 표시하고 검색에 한 이미지가 일치해도 해당 리소스의 전체 이미지를 보여줍니다. 미지원 하위 이미지는 자리와 오류 설명을 유지합니다.

`ResourcePreview`는 원본 이미지들을 순차 로딩해 256px 이하 타일의 모아보기 비트맵을 만듭니다. 최대 8열, 각 변 8192px 이내이며 이미지가 많은 경우 타일을 줄입니다. 타일을 더블클릭하면 기존 원본 미리보기로 들어가며 전체 보기로 복귀할 수 있습니다. 미번역 첨부 PNG는 타일 축소본이 아닌 각 원본 RGBA 이미지입니다.

GUI의 숨김 저장소는 resourceMode로 작동하고 리소스 ID 하나로 모든 하위 이미지를 숨기고 복원합니다. 미번역 `SaveResource`는 리소스 ID 하나에 `ResourceImages` 배열을 보관합니다. 배열은 이미지별 Texture 메타데이터와 PNG SHA-256 또는 미지원 이유를 포함합니다. 개별 확대 중이어도 숨김/기록 범위는 리소스 전체입니다. 이하 과거 개별 이미지 키 설명은 레거시 함수에 해당하며 현재 GUI 동작은 이 절이 우선합니다.


리소스 ID 전환 당시 사용자 요청으로 기존 숨김·미번역·캐시 초기화를 완료했습니다. 이후 업데이트에서는 기존 사용자 데이터를 유지하며 다시 초기화하지 않습니다. 원본 게임 파일을 변경하지 않습니다.

## 모듈

- `src/Core.cs`: 범위가 제한된 읽기, 메타데이터 모델, LZP2, 픽셀 디코더. 게임 경로를 참조하지 않음.
- `src/Formats.cs`: `ITextureReader` / `IContainerReader` 및 등록 배열. DDS, GTF, G1T, BNS를 별도 클래스로 구현. 폴더 탐색은 각 클래스의 시그니처 검사를 거침.
- `src/Viewer.cs`: 비동기 검색·취소, 가상 목록, 선택 시 디코딩, 캔버스, RAW, PNG/CSV 내보내기.
- `src/Loading.cs`: 작업 스레드와 모달의 수명 관리, 취소/완료/오류 전달, 미리보기·압축 해제 버퍼 LRU 캐시.
- 목록 선택 알림 안에서 모달을 직접 열지 않습니다. `SelectionPreviewQueue`가 BeginInvoke로 이벤트 반환 후 실행하고 연속 선택 요청은 최신 항목으로 합칩니다.
- `src/TexturePage.cs`: 전체 검색 결과와 네이티브 목록을 분리합니다. 목록/접근성 트리에는 최대 200개만 노출하고 이전·다음 페이지를 제공합니다. 검색·숨김 필터는 전체 항목에 적용한 후 페이지를 나눕니다.
- `src/HiddenImages.cs`: 영구 숨김 설정 저장소와 검색·체크 복원·전체 복원 관리 모달. `src/HiddenImagesTests.cs`에서 상태 유지와 복원 경로를 검증합니다.
- `src/Program.cs`: GUI 진입점, CLI, 회귀 검사.
- `scripts/verify_samples.py`: 별도 디코더 비교·폴더 원본 매니페스트.

새 텍스처 형식은 `ITextureReader.Matches/Parse`를 구현하고 `Formats.Readers`에 등록합니다. 새 아카이브는 `IContainerReader`에서 검증한 `Source` 범위를 반환하고 `Scanner.Containers`에 등록합니다. 새로운 압축 프로필은 기존 LZP2 조건을 느슨하게 만들지 말고 별도 디코더로 구현합니다. 현재 확장은 소스 빌드 방식이며 외부 DLL을 자동 실행하지 않습니다.

폴더 탐색에는 게임별 경로·항목 번호가 없습니다. BNS의 식별 상수, LZP2 프로필, G1T 버전/플랫폼은 디코더의 명시적 포맷 조건입니다. 프로필 불일치는 오류 또는 미지원으로 표시합니다. 다른 타이틀에서 같은 형식 이름만으로 호환성을 주장하지 않습니다.

## 한도와 보호

입력은 `FileAccess.Read`로만 엽니다. 파일당 128 MiB, LZP2 해제 64 MiB, 이미지 16M 픽셀/변 8192 한도가 있습니다. 대형 아카이브 인덱스와 RAW는 부분 읽기, 깊은 검색은 4 MiB 창과 3바이트 겹침으로 동작합니다. 파일당 깊은 검색 시그니처 후보가 20,000개를 넘으면 기록 후 중단합니다. 정션 디렉터리는 순환을 피하기 위해 제외합니다.

화면 비트맵은 하나만 유지합니다. 검색 결과는 픽셀 대신 소스 범위를 저장합니다. 미리보기 로더는 관리되는 BGRA 버퍼 128 MiB와 LZP2 해제 버퍼 64 MiB를 별도 LRU로 유지하며 화면 비트맵은 독립적으로 생성·해제합니다. 임시 디코딩 버퍼와 화면 비트맵 메모리는 이 캐시 한도와 별도입니다. 파일 경로·길이·수정시각·소스 범위와 모든 디코딩 조건으로 키를 구성하고, 재검색 시 초기화합니다. 파일 내용만 바꾸고 길이·수정시각을 그대로 유지했다면 재검색이 필요합니다.

비압축 미리보기는 픽셀 구간만 읽습니다. 입력 읽기는 1 MiB마다, 깊은 검색은 64 KiB마다 취소를 확인합니다. 깊은 검색의 바이트 루프는 문자열 검사 대신 시그니처 바이트를 비교합니다. 총량이 없는 단계는 모달의 marquee 표시를 사용하며 실제 내부 검색의 현재 파일 퍼센트는 단계 문자열로 표시합니다. 작업 스레드는 최신 상태 문자열만 교체하고 UI 타이머가 80 ms 간격으로 읽어 메시지 큐 누적을 피합니다. 취소 시 작업 종료 후 모달을 닫고, 검색은 부분 결과를 유지하며 이미지 결과는 폐기합니다. 일반 이미지의 GDI 디코딩 중 취소는 해당 네이티브 호출이 끝난 후 반영됩니다.

GUI 저장은 CreateNew로 기존 경로 덮어쓰기를 거부합니다. CLI 보고서 갱신은 명시적 `--overwrite`에서 허용합니다.

## 숨김 이미지

숨김 상태는 `settings/hidden-images.json`에 독립 보존합니다. 경로·소스 오프셋·픽셀 오프셋·디코딩 조건으로 SHA-256 키를 만들며 파일 수정시각·소스 길이·표시 이름은 제외합니다. 같은 아카이브의 다른 텍스처와 구분하면서 재검색과 캐시 삭제에도 숨김이 유지됩니다. 원본 경로나 텍스처 위치/형식이 달라지면 새 항목으로 취급됩니다.

GUI 목록 필터와 Preview 진입점에서 숨김을 적용합니다. 숨긴 현재 비트맵은 즉시 해제합니다. 원본 파일·미번역 PNG를 삭제하거나 수정하지 않습니다. CSV는 기존처럼 전체 검색 결과를 내보냅니다. 관리 모달에서는 검색 필터를 바꾸어도 체크한 항목을 유지하고 저장 성공 후에만 목록을 갱신합니다.

숨김 저장 성공 후 `HideNavigation.Next`가 현재 필터의 전체 목록에서 다음 지원 이미지를 고릅니다. 다음 항목이 없으면 이전 이미지로 이동하며, 대상의 새 인덱스로 페이지를 계산하고 선택 이벤트를 통해 미리보기를 예약합니다. `ProcessCmdKey`에서 보조키 없는 H를 처리하되 텍스트·숫자·콤보 입력과 로딩 중에는 가로채지 않습니다. 키 메시지의 이전 눌림 비트로 자동 반복 숨기기를 억제합니다.

설정 변경은 이름 있는 뮤텍스 안에서 최신 JSON을 다시 읽어 병합한 뒤 임시 파일·원자 교체로 저장합니다. 저장 실패 시 기존 메모리 상태를 유지하고 오류를 표시합니다. 손상된 설정은 자동으로 덮어쓰지 않습니다. 다른 실행 중인 창의 설정 변경은 해당 창에서 관리 모달을 열어 새로 읽을 수 있습니다.

현재 GTF remap, 나머지 밉·면, 3D, G1T 확장 헤더 변형 및 다른 전용 컨테이너는 이후 확장 대상입니다. 텍스처의 게임 내 UV와 스프라이트 조합 정보는 해석하지 않습니다. CPU 표준 BC 보간 결과는 실기 GPU의 세부 반올림과 다를 수 있습니다.

## 미번역 전달 기록

`src/TranslationQueue.cs`는 `TranslationStore`, 기록 메모 창, 200개씩 표시하는 관리 창을 구현합니다. `src/TranslationQueueTests.cs`가 보존·내보내기 회귀 검사를 수행합니다. 숨김 ID와 같은 경로/위치/해석 조건의 SHA-256을 `Id`로 사용하며 중복 등록은 현재 기록을 갱신합니다. `untranslated/untranslated.json`은 버전 1, Images 배열이며 Texture/Source 전체 필드, 원본 크기·수정시각·SourceStamp, 루트/상대 경로/게임명(검색 시 알려진 경우), 메모, 관심 영역, 기록 시각, PNG SHA-256을 보관합니다.

픽셀은 현재 미리보기의 독립 복제로부터 PNG로 저장합니다. 보기 채널·격자·확대는 적용하지 않습니다. 미리보기 시작/종료 시 원본 stamp를 비교하고 기록 저장 직전/후에도 확인하여 변경된 소스에 오래된 미리보기를 연결하지 않습니다. 크기·수정시각을 유지한 원본 변경까지 감지하는 전체 파일 해시는 아닙니다.

설정은 이름 있는 뮤텍스 안에서 다시 읽고 원자 교체하며, PNG는 내용 해시 이름으로 별도 보존합니다. 캐시 정리와 숨김 설정은 영향을 주지 않습니다. 기록 제거·갱신 시 이전 PNG는 보존하지만 이전 JSON 기록을 버전 관리하지는 않습니다. PNG에 대한 자동 정리와 번역 진행 상태는 현재 없습니다. JSON은 32 MiB 한도이며 손상되면 자동 덮어쓰지 않습니다.

내보내기는 검증된 PNG만 새 `.partial` 폴더로 복사하고 JSON·README.txt 기록 완료 후 최종 폴더 이름으로 변경합니다. 기존 전달 폴더를 덮어쓰지 않습니다. 취소/실패 시 남은 `.partial`은 미완성입니다. Codex나 외부 서비스에 직접 전송하는 기능은 아닙니다.

- [Microsoft Block Compression](https://learn.microsoft.com/en-us/windows/win32/direct3d10/d3d10-graphics-programming-guide-resources-block-compression): BC1/2/3 블록 및 알파 보간.
- BNS/LZP2/G1T는 검증한 프로필만 지원합니다. 게임별 외부 프로젝트 스크립트를 앱 런타임에서 불러오지 않습니다.

공개 코드를 복사하거나 외부 코덱 바이너리를 배포하지 않았습니다. 포맷 문서와 기존 프로젝트 분석을 바탕으로 C# 디코더를 작성하고 Pillow와 독립 비교합니다. 앱에 게임 데이터·키·번역 패치를 포함하지 않습니다.

## 재현성

Windows 내장 Framework C# 컴파일러를 사용합니다. 고정 경로 `dist`에 갱신하며 결과 SHA-256은 `dist/sha256.json`에 기록합니다. 이 레거시 컴파일러의 PE 타임스탬프/MVID 때문에 **EXE 바이트 단위 결정적 빌드는 보장하지 않습니다**. 입력 픽셀 디코딩과 테스트 픽셀 해시는 결정적입니다. 코드 변경·실행 검증은 별도 기록으로 구분합니다.
