# PS3 Atlas Viewer

복호화된 PS3 게임 폴더나 추출된 리소스 폴더를 열어 텍스처·폰트 아틀라스를 탐색하는 Windows 데스크톱 도구입니다. 게임 경로, 제품 ID, 리소스 번호를 프로그램에 고정하지 않았습니다. 모든 파일은 읽기 전용으로 열고 추출물은 별도로 저장합니다.

디스크 캐시는 제거했습니다. 미리보기는 **메모리 캐시 → 원본 디코딩** 순서로 읽으며 PNG/JSON 캐시를 자동 저장하지 않습니다. 이미지 메모리 캐시 128 MiB와 압축 해제 메모리 캐시 64 MiB는 유지합니다.

## 실행

`launch.cmd` 또는 `dist/PS3AtlasViewer.exe`를 실행한 뒤 **폴더 선택**을 누르세요. 폴더를 창에 끌어놓거나 경로를 입력하고 **다시 검색**을 눌러도 됩니다. Windows x64와 .NET Framework 4.5 이상이 필요합니다. 개발에 사용한 환경은 Windows의 .NET Framework 4.x이며, 별도 SDK·Python·Node 설치 없이 EXE를 실행할 수 있습니다.

- 왼쪽 검색칸: 경로, 내부 항목 번호, 포맷 검색. `BC3`, `entry 000004`처럼 입력합니다.
- 목록 한 줄은 **원본 파일 경로 + 내부 리소스 오프셋**인 리소스이며 `LINKDATA_BNS.LNK @0x...`와 이미지 개수를 표시합니다. 오른쪽은 기본 **목록 순서대로 8개 리소스씩** 함께 보여줍니다. 예를 들어 1~8번째 줄은 첫 묶음, 9~16번째 줄은 다음 묶음입니다. 한 리소스에 이미지가 여러 개면 모두 표시하므로 화면 이미지 수는 8개보다 많을 수 있습니다.
- 오른쪽 아래 **묶음 크기**를 1~32개로 변경하고 **이전 묶음 / 다음 묶음**으로 이동합니다. 검색·숨김·미번역 제외 후의 목록 순서로 묶으며 마지막 묶음은 남은 개수만 표시합니다. 크기 1은 기존 개별 리소스 보기입니다.
- 묶음 이미지 클릭은 해당 리소스와 왼쪽 줄을 선택하며 청록색 테두리로 대상을 표시합니다. 더블클릭하면 원본 이미지를 개별 확대합니다. **묶음 보기**로 복귀하고, **리소스 전체 보기**는 선택한 리소스 하나의 모든 이미지를 보여줍니다. 검색에 이미지 하나가 일치해도 해당 리소스의 전체 이미지를 유지합니다.
- **리소스 전체 숨기기(H) / 리소스 미번역 기록**은 선택 대상 하나에 적용합니다. **묶음 전체 숨기기 / 묶음 전체 미번역 기록**은 현재 표시 묶음 전체에 적용하고 다음 남은 리소스로 이동합니다. 일괄 기록도 리소스별 항목으로 저장하므로 관리 창에서 각각 복원·제거할 수 있습니다. 묶음 미번역 메모는 한 번 입력하며 모든 대상에 같은 메모를 저장합니다.
- 묶음 보기의 **PNG 저장**은 선택한 리소스의 원본 PNG들을 저장합니다. 영역 저장은 더블클릭해 개별 확대 후 사용합니다. 묶음 미리보기는 임시 화면이며 미번역 PNG는 원본 이미지별로 유지합니다.
- 목록은 대량 항목에서도 창이 멈추지 않도록 **200개씩** 표시합니다. 아래 **이전/다음**으로 페이지를 이동하며, 검색칸은 현재 페이지만이 아니라 전체 결과를 검색합니다.
- 미지원 포함: 이미지 외 파일과 미지원 항목을 함께 봅니다. 자세한 이유는 하단 정보에 표시합니다.
- 파일 내부 검색: 미지원 파일 안의 DDS/GTF/G1T 시그니처를 찾아 헤더·크기·데이터 범위를 검사합니다. 압축이나 암호화를 해제하는 기능과는 다릅니다. PAM/AT3/G1L/PUP는 제외하며, 이미 인식한 컨테이너는 등록된 해석기를 사용합니다.
- 검색·이미지 선택 시 **읽는 중** 모달에 현재 파일/처리 단계와 움직이는 진행 표시줄을 표시합니다. 전체 작업량을 모르는 단계는 퍼센트를 추정하지 않습니다. 내부 검색의 퍼센트는 현재 파일 기준이며, 취소 버튼 또는 창 닫기로 중지할 수 있습니다. 검색 취소 시 찾은 항목은 유지됩니다.
- 빠른 작업도 진행창을 최소 약 0.3초 표시하며 작업이 끝나면 즉시 ‘완료’로 바꿉니다. 이미지 선택 후 하단에는 **메모리 캐시 / 원본 디코딩** 출처, 실제 처리 시간, 메모리 캐시 이미지 수·사용량이 남습니다. 처리 시간에는 완료 표시 대기 시간을 포함하지 않습니다.
- 디코딩한 이미지는 메모리에서 128 MiB, LZP2 해제 데이터는 64 MiB까지 재사용합니다. 오래된 항목부터 비우며 다시 검색하면 초기화합니다. 비압축 텍스처는 선택한 최상위 밉의 픽셀 구간만 읽습니다. 첫 검색과 처음 여는 대형 이미지에는 처리 시간이 필요합니다.
- 리소스 숨기기: 목록에서 리소스를 선택한 뒤 **리소스 전체 숨기기 (H)**를 체크하거나 **H** 키를 누르면 내부 이미지 전체를 숨기고 다음 리소스를 자동 선택합니다. 페이지 끝에서도 이어서 이동하며 마지막 리소스라면 이전 리소스를 선택합니다. 폴더 재검색에도 적용됩니다. 검색·경로·숫자 입력칸에서는 H를 문자 입력으로 처리하며, 키를 길게 눌러도 연속으로 숨기지 않습니다.
- **숨김 목록** 버튼은 별도 관리 모달을 엽니다. 경로·항목·포맷으로 검색하고 **체크 항목 복원** 또는 **전체 복원**으로 다시 표시할 수 있습니다. 복원 후 창을 닫으면 현재 목록에 반영됩니다. 현재 검색 결과에 없는 항목은 원본 폴더를 다시 검색해야 표시됩니다.
- 숨김 설정은 EXE 옆 `settings/hidden-images.json`에 보존합니다. 원본 이미지를 삭제하지 않으며 앱 재시작과 원본 수정시각 변화에도 유지됩니다. 숨김 목록 자체에는 100개 제한을 적용하지 않습니다.
- 숨김 관리 창도 **200개씩** 표시합니다. 검색은 모든 숨김 항목에 적용되며 **검색 결과 체크**는 페이지 밖의 검색 결과까지 체크합니다. 체크 상태는 페이지·검색을 바꿔도 유지됩니다.
- 숨김 목록의 **행을 선택하면 오른쪽에 이미지가 표시**됩니다. 복수 이미지 리소스는 전체 보기, 더블클릭은 개별 확대입니다. 읽는 중에는 진행 표시와 중지 버튼이 나오며 다른 행을 선택하면 이전 읽기를 취소합니다. 이미지 보기만으로 숨김 상태가 바뀌지 않습니다. 파일을 옮기거나 삭제한 항목은 오류를 표시하고 기록은 유지합니다.
- 휠: 확대·축소. 오른쪽/가운데 드래그: 이동. 맞춤·1:1 버튼도 사용할 수 있습니다.
- RGBA/RGB/알파/R/G/B와 체커·검정·흰 배경: 색상과 투명도를 확인합니다.
- 격자: 셀 너비·높이를 직접 지정합니다. 게임의 실제 글리프/UV 메타데이터를 자동 추정하지 않습니다.
- 왼쪽 드래그: 영역 선택. PNG 전체 또는 선택 영역을 저장할 수 있습니다.
- **PNG 저장은 원본 RGBA**를 출력합니다. 화면 채널 필터, 격자, 배경, 확대는 포함하지 않습니다. 출처·오프셋·크기·PNG SHA-256을 `.png.json`에 함께 저장합니다. 기존 파일은 덮어쓰지 않습니다.
- 복수 이미지 전체 보기에서 **PNG 저장**은 새 폴더에 원본 PNG들을 각각 저장하고 `resource.json`에 전체 메타데이터를 기록합니다. 개별 확대 상태에서 PNG/영역 저장은 해당 이미지에 적용하지만, **숨김과 미번역 기록은 항상 현재 리소스 전체**에 적용합니다.
- 목록 CSV: 미지원 항목과 탐색 기록을 포함한 전체 목록을 저장합니다.

앱은 마지막으로 검색한 폴더를 `settings/viewer.json`에 저장하고 다음 실행 때 경로 칸과 폴더 선택 창에 복원합니다. **파일 내부 검색**은 매 실행 시 기본으로 켜집니다. 시작 시 목록은 비어 있으며, 복원된 폴더를 검색하려면 **다시 검색**을 누릅니다. 저장된 폴더가 이동·삭제되었다면 새 폴더를 선택하세요.

## 미번역 이미지 기록과 Codex 전달

1. 오른쪽에 기록할 리소스를 열고 **리소스 미번역 기록**을 누릅니다. 개별 확대 중이어도 같은 내부 리소스 전체를 기록합니다.
2. 미번역 문구나 위치를 메모하고 **기록 저장**을 누릅니다. 메모는 생략할 수 있습니다. 리소스 안의 모든 지원 이미지의 RGBA PNG와 각 원본 위치·포맷·해석 조건을 저장합니다. 미지원 이미지의 메타데이터와 이유도 함께 기록합니다.
3. **미번역 목록 / 전달**에서 검색·확인·선택 기록 제거를 할 수 있습니다. **목록 경로 복사**로 JSON 경로를 복사하여 Codex에 알려주면 됩니다.

4. 다른 위치에 자료를 모으려면 **Codex 전달 폴더 저장**을 누릅니다. 검색 필터와 무관하게 전체 목록의 `untranslated.json`, `README.txt`, `images/`를 새 폴더에 저장하고 폴더 경로를 클립보드에 복사합니다.

미번역 기록을 저장하면 해당 리소스는 기본 탐색 목록에서 빠지고 다음 리소스가 선택됩니다. 마지막 항목이면 이전 항목을 선택합니다. 재검색·앱 재시작에도 기록된 리소스를 제외합니다. 미번역 관리에서 기록을 제거하고 창을 닫으면 기본 목록에 다시 표시됩니다. 별도로 숨김 처리한 리소스는 숨김을 복원해야 표시됩니다.

원본 기록은 EXE 옆 `untranslated/untranslated.json`과 `untranslated/images/<PNG SHA-256>.png`입니다. 재시작해도 유지합니다. 같은 리소스 ID를 재등록하면 메모와 전체 이미지 기록을 갱신합니다. 목록에서 제거해도 원본·보관 PNG는 삭제하지 않습니다. 숨김 목록과 별개이며, 번역 완료 항목은 기록에서 제거하는 방식입니다. 현재 번역 진행 상태나 변경 이력 관리는 없습니다.

원본이 바뀐 뒤에는 이미지를 다시 열어 기록하세요. 원본 전체 파일 해시 대신 크기·수정시각과 디코딩 위치를 저장하며, PNG는 SHA-256으로 검증합니다. 내보내기가 취소·실패한 경우 `.partial` 폴더는 미완성 자료입니다. 원본 게임 수정이나 외부 전송은 수행하지 않습니다.

## 현재 지원 범위

| 종류 | 지원 |
|---|---|
| 일반 이미지 | PNG, JPEG, BMP, GIF 선두 시그니처; 확장자와 무관하게 탐지, GIF는 첫 프레임 |
| DDS | DXT1/3/5 (BC1/2/3), 16/24/32비트 RGB 마스크, L8 |
| GTF | 버전 020000FF/020100FF/020200FF, 복수 텍스처, 2D B8/ARGB8888/ARGB1555/ARGB4444/RGB565/DXT1/3/5 |
| GTF 배치 | 비압축 선형 피치 또는 2의 거듭제곱 Morton; DXT 블록 선형 |
| G1T | `G1TG0050`/`G1TG0060`, 플랫폼 1, BC1/2/3; 0060 확장 헤더 12바이트의 선형 ARGB 형식 1 |
| BNS | 선두 00019DAD, BE 위치 단위·길이 인덱스 프로필. 파일명에 의존하지 않음 |
| LZP2 | 5C8F823F 프로필의 리터럴/RLE/LZ 해제, 범위·종료 패딩 검사 |
| RAW | 오프셋, 너비, 높이, 행 피치, RGBA/ARGB/BGRA/L8/A8/BC1/2/3; 비압축 Morton 선택 |

자동 뷰는 **최상위 밉·첫 면**만 표시합니다. GTF 채널 remap은 메타데이터에 표시하되 적용하지 않습니다. 3D, DDS DX10/BC7, 다른 G1T 플랫폼·변형, 미지의 전용 압축/컨테이너는 미지원으로 남깁니다. 이미지 종류를 폰트/메뉴/배경으로 자동 판별하거나, 게임 화면을 재조립하거나, 게임 파일을 수정·재삽입하지 않습니다.

‘범용’은 공통 포맷 탐지·내부 검색·RAW 해석과 확장 가능한 디코더 구조를 뜻합니다. 모든 PS3 게임의 독자 압축을 무설정으로 지원한다는 뜻은 아닙니다. 다른 게임의 전용 포맷은 샘플 검증 후 독립 해석기를 추가합니다.

## RAW 해석

미지원 항목을 선택하고 **RAW 해석**을 누릅니다. 오프셋은 선택한 파일/내부 항목의 시작 기준이며 `0x` 16진수 또는 10진수로 입력합니다. LZP2 항목의 오프셋은 압축 해제 버퍼 기준입니다. 대형 원시 파일에서는 지정 오프셋부터 필요한 픽셀 범위만 읽습니다. 입력한 조건으로 보이는 그림이 실제 형식과 같다는 보장은 없으므로 자동 인식 결과와 구분해 표시합니다.

## 빌드와 검증

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
.\dist\AtlasCheck.exe --scan "D:\Games\Decrypted" "D:\Reports\Atlas" --deep
```

`build.ps1` 하나가 GUI와 CLI를 빌드하고 `-Test`에서 코덱·경계·원본 보존·PNG 검사까지 실행합니다. CLI의 `--scan`은 전체 목록, 구조 검증, 표본 디코딩과 PNG를 출력합니다. 재실행 시 같은 작업 보고서를 갱신하려면 `--overwrite`를 추가합니다. 보고서 출력은 입력 폴더 밖이어야 합니다. CLI 표본 디코딩은 전체 픽셀 전수검사와 구분합니다.

선택적으로 Python/Pillow가 설치된 검증 환경에서 `python scripts/verify_samples.py <보고서 폴더> --manifest`를 실행하면 별도 LZP2 구현·Pillow 디코딩과 픽셀을 비교하고 원본 파일별 해시를 생성합니다. 이 도구는 앱 실행 의존성이 아닙니다.

기술 구조·추가 포맷 구현은 [개발 문서](docs/DEVELOPMENT.md), 검증 방법과 범위는 [테스트 안내](docs/TESTING.md)를 참고하세요.
